# Postdoc Positions in Physical AI – IBRS, TUM MIRMI

Job posting page for multiple postdoctoral positions (TV-L E13, Stufe 3–4) in Physical AI at the
TUM RoboGym powered by NEURA, Intelligent Bio-Robotic Systems group, TUM MIRMI.

The site is a single static page (`index.html`) served with GitHub Pages.

## Publishing

1. Push this folder to a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The page will be live at `https://<user-or-org>.github.io/<repo-name>/` within a minute or two.
